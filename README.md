# Portfolio

A black-and-white minimal portfolio for Aayan Ahmed.

## Overview
This is a static portfolio site built for Vercel. It highlights leadership, research, AI, education, and public impact work in a minimal monochrome aesthetic inspired by editorial portfolios.

## Local preview
Open `index.html` in a browser, or run a tiny local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy on Vercel
1. Push this repo to GitHub.
2. Import the repository in Vercel.
3. Use the default settings. This is a static project, so no build command is needed.
4. Publish the project.

## Files
- `index.html` — portfolio content and structure
- `styles.css` — black-and-white minimal styling
- `script.js` — subtle interactions and current year
- `README.md` — project overview and deploy guide

## Notes
The content is tailored to Aayan Ahmed’s background, project work, leadership roles, and certifications using the information provided.
