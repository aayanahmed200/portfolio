AI · NLP · ACCESSIBILITY · 2026—PRESENT

Zariya

ZARIYA / OFFLINE-FIRST AI

An offline-first AI assistant exploring practical applications of AI for Urdu and other low-resource languages. The active web-app iteration uses a Flask backend and local model inference through Ollama, with a lightweight offline knowledge engine as a fallback. A separate Streamlit version uses a local GGUF model.

The project focuses on accessibility and reducing dependence on continuous internet connectivity for AI-assisted interaction.

GitHub repository ↗Repository project · no separate public site preview

HEALTHTECH · PRODUCT CONCEPT · 2026

RemiChain

R
SUPPLY · MATCH · REDISTRIBUTE

Developed a healthcare technology concept designed to connect surplus medical supplies with facilities and individuals who need them. The repository contains a Flask application and a matching engine that scores possible donation-to-request pairs using urgency, proximity, quantity match and expiry proximity.

The concept explores technology-driven ways to improve the distribution and utilisation of available medical resources.

GitHub repository ↗Repository project · no separate public site preview

RESEARCH · COMPUTER VISION · 2026

Diabetic Retinopathy Detection

ICDR SEVERITY SCALE · PROJECT FIGURE

Conducted a mini-project evaluating three AI models for their ability to detect diabetic retinopathy from retinal images. Designed comparative testing to examine how different models interpreted medical images and identified signs of the condition.

The repository README states that the checked-in pilot results use synthetic data and seeded mock predictions, not real model inference. This is disclosed in the project repository.
