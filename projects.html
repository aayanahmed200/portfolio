HEALTHTECH · FLASK PROTOTYPE

RemiChain

A locally runnable Flask prototype that matches surplus medical supplies with facility requests. Its matching engine scores urgency, proximity, quantity fit and expiry proximity; it avoids duplicate proposals and supports partial request fulfilment.

Its pytest suite covers matching scores, expiry handling and ranked recommendations.

RESEARCH · COMPUTER VISION

Diabetic Retinopathy Detection

A mini-project comparing three AI models on retinal images to explore how they identify signs associated with diabetic retinopathy.

The checked-in pilot uses synthetic metadata and seeded mock predictions, not real model inference. The real pipeline has not yet been run, so its pilot metrics must not be presented as model accuracy. This is a notebook-based research pipeline, not an interactive web demo.

GitHub repository ↗

AI · NLP · ACCESSIBILITY · IN DEVELOPMENT

Zariya

An offline-first AI assistant for Urdu and other low-resource languages. Its Flask web app uses local-model inference and token streaming, with an offline knowledge engine as a fallback; an earlier Streamlit implementation is also retained.

The repository includes a 570-prompt regression harness for the offline knowledge engine. Run the web app locally using its setup guide.
