RESEARCH · COMPUTER VISION

Diabetic Retinopathy Detection

A mini-project comparing three AI models on retinal images to explore how they identify signs associated with diabetic retinopathy.

The checked-in pilot uses synthetic metadata and seeded mock predictions, not real model inference. The real pipeline has not yet been run, so its pilot metrics must not be presented as model accuracy. This is a notebook-based research pipeline, not an interactive web demo.

AI · NLP · ACCESSIBILITY

Zariya

An offline-first AI assistant exploring practical applications of AI for Urdu and other low-resource languages. The web-app iteration uses a Flask backend and local model inference, with a lightweight offline knowledge engine as a fallback.

The repository includes a 570-prompt regression harness for the offline knowledge engine. Run the web app locally using its setup guide.

GitHub repository ↗

HEALTHTECH · PRODUCT CONCEPT

RemiChain

A healthcare technology concept connecting surplus medical supplies with facilities and people who need them. The repository contains a Flask application and a matching engine that considers urgency, proximity, quantity and expiry.

A locally runnable Flask prototype; its pytest suite covers matching scores, expiry handling and ranked recommendations.
